# Midas Core: Distributed Real-Time Risk & Financial Data Pipeline

An enterprise-grade, high-throughput streaming and data persistence architecture built to ingest, validate, and store synthetic financial transaction streams generated by a pre-trained Generative Adversarial Network (GAN).

## 🚀 Architecture Overview
1. **Producer Layer:** A Python script loads a deep learning GAN model (.h5) and scalers, generating batches of synthetic transactions in memory at ~17,000+ msgs/sec.
2. **Streaming Layer:** Apache Kafka (running via Docker in KRaft mode) buffers and streams the JSON payloads over `synthetic-tx-stream`.
3. **Consumer & Persistence Layer:** A Java Spring Boot microservice utilizes Spring Kafka for batch consumption, applies real-time risk validation logic, and executes high-efficiency chunked batch inserts (JDBC batch size: 1000) into a PostgreSQL data warehouse.

## 🛠️ Tech Stack
* **Language/Framework:** Java 17+, Spring Boot, Spring Data JPA, Hibernate
* **Messaging & Streaming:** Apache Kafka, Confluent Kafka Python
* **Database:** PostgreSQL
* **Machine Learning & Data:** TensorFlow, Keras, Scikit-Learn, Pandas, NumPy
